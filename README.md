# Readr

A reading tracker with subscriptions, community, and insights.

## What it does

- Reading insights
- subscriptions
- recommendations
- community
- OCR

## Targets

- iOS with widgets

## Structure

Key types:

- ``ReadingInsightsService``
- ``RecommendationService``
- ``OCRService``
- ``CrossDeviceSyncService``
- ``DatabaseService``

Has a `PricingView` and `SubscriptionsView` — the batch's few with real commercial surfaces.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.
